# Dynamic features — plan (replica, hands-off)

Source of truth: `stardust/dynamic-features.md` (13 rows, every row dispositioned). The static migration never waits on this plan.

## Phase I — Interactive chrome (self, ships autonomously)

- **Deliverable:** the header menus (Discover / Impact / Shop), the mobile drawer and the "Filter Icon" popup are rebuilt as runtime JS in the header block, per `stardust/chrome/header-contract.json`. The Sign Up / Log In controls render without a backend (A-1).
- **Authoring contract:** nav document (header fragment). There is no extra block config.
- **Verify:** chrome-compare against the header contract at 1440 and 360. Add a parity row per family.
- **Effort:** inside the replica header work.

## Phase II — Martech scaffold (owner-gated, shipped off)

- **Deliverable:** `stardust/martech-contract.json` and `stardust/martech-handoff.md`; `scripts/martech.js` generated by `martech-scaffold.mjs` and hooked into `loadEager()` (`loadConsent()`), `scripts/consented.js` (`loadTags()`) and `scripts/consent-check.js` (`hasConsent()` delegates to martech.js). Every part is `enabled: false`: `consent.cmp`, routes `google-tag-manager-1/2`, `aemMartech`. `target` is null.
- **Owner enablement (A-2, A-3, A-4, A-5):** follow `stardust/martech-handoff.md`. Set `enabled: true`, re-run `martech-scaffold.mjs`, preview with `?martech=on&consent=accept`, and rewrite the listed GTM rules. Collector/edge CNAMEs are an owner item.
- **Verify (post-deploy):** `dynamics-check.mjs` adds the `martech` feature automatically while the contract exists. `/` must request no CMP or route host (all off).
- **Effort:** done (scaffold); enabling is owner time.

## Phase III — Deferred to rollout (static-snapshot, undecided)

- Auth dialogs and reCAPTCHA (A-1): revisit at rollout once the owner decides auth on the new host.
- `CQ` global: no consumer, nothing ships.

## Named assumptions (hands-off)

A-1 auth, A-2 OneTrust domain script reuse, A-3 GTM containers, A-4 Web SDK and CNAMEs, A-5 tagging plan. These are the run's assumptions, recorded for the owner's decision batch. None of them is decided-out.
